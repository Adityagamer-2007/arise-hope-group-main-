## 📦 Getting Started & Local Development

### Prerequisites
- Node.js (v18 or higher recommended; tested on v24.21.0)
- npm (v9 or higher; tested on v11.19.0)

### 1. Installation
Clone or extract the project archive, then install dependencies:
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open your browser to `http://localhost:3000` (or the port specified in terminal).

### 3. Production Build
```bash
npm run build
```
Generates an optimized, tree-shaken static bundle in the `dist/` directory ready for deployment.

### 4. Local Production Preview
```bash
npm run preview
```

---

## 🌐 Production Deployment

The generated `dist/` folder can be hosted instantly on any modern static hosting service:
- **Vercel:** Run `vercel deploy` or connect Git repository.
- **Netlify:** Drag and drop `dist/` or configure build command `npm run build` with publish directory `dist`.
- **Cloudflare Pages / AWS S3 / Nginx:** Serve `dist/` with single-page application fallback routing to `index.html`.
